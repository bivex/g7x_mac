# CanonSync (macOS) 📸

Нативная консольная утилита для macOS на **Swift**, позволяющая автоматически обнаруживать камеру **Canon PowerShot G7 X Mark II** (а также любые другие камеры Canon / PTP-IP) по **Wi-Fi** (через Apple Bonjour / PTP-IP) или **USB**, открывать сессию и автоматически скачивать фото и видео.

---

## ⚡ Особенности

* **Нативный стек Apple**: Использует системный фреймворк `ImageCaptureCore` (на базе которого работает системный *«Захват изображений» / Image Capture*).
* **Автоматический мониторинг (Watch mode)**: Утилита слушает сеть в фоновом режиме. Как только вы включаете Wi-Fi на камере и подключаетесь к Mac, снимки автоматически загружаются на компьютер.
* **Умная дедупликация**: Пропускает уже скачанные файлы (сверяет размер и имя), не перезаписывая их заново.
* **Сортировка по датам**: Автоматически раскладывает снимки по папкам вида `~/Pictures/Canon_G7X/YYYY-MM-DD/`.
* **Фильтрация форматов**: Опции для загрузки только RAW (`.CR2`) или только JPEG (`.JPG`).
* **Безопасность**: Файлы на SD-карте камеры по умолчанию сохраняются и не удаляются.

---

## 🚀 Сборка и запуск

### Быстрый запуск
```bash
swift run CanonSync
```

### Сборка релизного бинарника
```bash
make release
# или: swift build -c release
```

Бинарник будет находиться по пути: `.build/release/CanonSync`.

---

## ⚙️ Параметры запуска

```text
📸 CanonSync — Утилита автосинхронизации фото по Wi-Fi / USB (PTP-IP / Bonjour)

Использование:
  swift run CanonSync [опции]

Опции:
  -d, --dir <путь>     Папка для сохранения (по умолчанию: ~/Pictures/Canon_G7X)
  --no-date            Не разбивать файлы по подпапкам с датами (YYYY-MM-DD)
  --once               Завершить работу после первой синхронизации
  -l, --list           Только показать список обнаруженных камер и файлов (без скачивания)
  --raw                Скачивать только RAW-файлы (.CR2, .CR3, .RAW)
  --jpg, --jpeg        Скачивать только JPEG-файлы (.JPG, .JPEG)
  --delete-after       Удалять файлы с камеры после успешного скачивания (ОСТОРОЖНО!)
  -h, --help           Показать эту справку
```

## 📡 Подключение Canon G7 X Mark II по Wi-Fi

1. Убедитесь, что Mac и камера подключены к одной Wi-Fi сети (2.4 ГГц).
2. Запустите утилиту: `swift run CanonSync`
3. На камере нажмите кнопку **Wi-Fi** → значок **Компьютер** → **Добавить устройство**.
4. Камера обнаружит ваш Mac по Bonjour → выберите имя вашего компьютера.
5. Утилита автоматически установит соединение и скачает все новые кадры!
